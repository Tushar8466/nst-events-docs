# Archive Notice

**Status:** SUPERSEDED & ARCHIVED
**Migration Date:** August 8, 2026

## Why this repository was retired
The `nst-events-docs` repository was historically used as an external repository for project documentation, architectural diagrams, and features specifications. This created a split source of truth, causing documentation drift and breaking the atomic nature of pull requests (where code and documentation should update simultaneously).

## Where did the documentation move?
All documentation has been successfully migrated, consolidated, and heavily audited. The new, single canonical source of truth for both the codebase and the documentation is the primary repository:

**New Location:** [nst-events/docs](https://github.com/sohamdhande/nst-events/tree/main/docs)

## Archival Policy
This repository has been placed in read-only mode. 
- Do **NOT** submit pull requests to this repository.
- Do **NOT** reference this repository in new documentation.
- The history is preserved here strictly for auditing and historical context, but the files will no longer be updated.

If you are looking for the latest Architecture Decision Records (ADRs), Engineering Handbook policies, or Feature Specs, please visit the `nst-events` repository.
